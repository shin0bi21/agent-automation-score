# Skill routing tree

The tree displays normalized, observable guidance-file reads. It may connect a prompt boundary to an explicit `AGENTS.md` or `SKILL.md` read and to later content-free execution totals in that episode.

It must not claim that reading a skill proves semantic adherence, attribute all elapsed prompt time to a skill, expose skill contents copied into model context, or reconstruct private reasoning. Plugin ownership is presentation metadata derived from a namespaced normalized skill name.
